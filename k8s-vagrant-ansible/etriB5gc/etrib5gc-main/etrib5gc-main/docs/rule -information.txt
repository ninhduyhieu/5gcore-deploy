### PFCPSMReq-Flags

Flags applicable to the PFCP Session Modification Request message.

PFCPSMReqFlags_DROBU: Drop Buffered Packets - drop the downlink data packets currently buffered in the UP function

PFCPSMReqFlags_SNDEM: Send End Marker Packets -  UP function construct and send End Marker packets towards the old F-TEID of the downstream node when switching to the new F-TEID.

PFCPSMReqFlags_QAURR: Query All URRs - UP function returns 
immediate usage report(s) for all the URRs previously provisioned for this PFCP session.


### Apply Action

Apply to packets. In code of go-pfcp: DDPN, BDPN, and EDRT are set to "0"

ApplyAction_DROP: drop the packets

ApplyAction_FORW: forward the packets

ApplyAction_BUFF: buffer the packets

ApplyAction_NOCP: notify the CP function about the arrival of a first downlink packet being buffered. 

ApplyAction_DUPL: duplicate the packets. 

ApplyAction_IPMA: accept UE requests to join an IP multicast group. 

ApplyAction_IPMD: deny UE requests to join an IP multicast group. 

ApplyAction_DFRT: duplicate the packets for redundant transmission

ApplyAction_EDRT: eliminate duplicate packets used for redundant transmission

ApplyAction_BDPN: notify the CP function about the first buffered DL packet for downlink data delivery status notification. 

ApplyAction_DDPN:  notify the CP function about the first discarded DL packet for downlink data delivery status notification if the DL Buffering Duration or DL Buffering Suggested Packet Count is exceeded.
